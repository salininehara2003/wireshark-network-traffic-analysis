
# ICMP Traffic Analysis

## Objective
To capture and analyze ICMP Echo Request and Echo Reply packets using Wireshark.

## Activities Performed
- Generated ICMP traffic using the ping command.
- Captured Echo Request and Echo Reply packets.
- Identified source and destination IP addresses.
- Examined TTL, packet size and response time.

## Wireshark Display Filter
`icmp`

## Key Learning Outcomes
- Understood ICMP communication.
- Identified ping request and reply messages.
- Learned how ICMP helps troubleshoot network connectivity.

## Evidence
This folder contains screenshots of:
- Command Prompt ping results.
- Wireshark ICMP packet list.
- Expanded IPv4 and ICMP packet details.
