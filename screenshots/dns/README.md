
# DNS Traffic Analysis

## Objective
To capture and analyze DNS queries and responses using Wireshark.

## Activities Performed
- Executed `nslookup example.com`.
- Captured DNS query and response packets.
- Identified A and AAAA DNS record types.
- Examined DNS server communication.
- Observed UDP port 53 communication.

## Wireshark Display Filter
`dns`

## Key Learning Outcomes
- Understood domain name resolution.
- Identified DNS queries and responses.
- Learned the purpose of A and AAAA records.
- Understood the role of DNS in network communication.

## Evidence
This folder contains screenshots of:
- Command Prompt nslookup results.
- Wireshark DNS query packets.
- Expanded DNS query details.
- DNS response and returned IP addresses.
